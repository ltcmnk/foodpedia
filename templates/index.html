Sobre o Projeto

O que é
o Foodpedia?

Foodpedia é uma enciclopédia culinária viva. Não tem banco de dados fixo — cada receita é consultada em tempo real, como se você perguntasse a um chef de memória longa.

A estrutura editorial do livro serve de cenário para essa conversa. O ritmo de virar páginas é o ritmo de esperar por uma resposta boa.

As dez receitas base são clássicos com história. A décima-primeira pode ser qualquer coisa que você quiser descobrir.

{% include 'svg/divider.svg' %}
Foodpedia 2
Como Usar

Navegue pelo livro usando o sumário ou virando as páginas pelos cantos. As seis receitas clássicas estão sempre disponíveis para leitura.

Para consultar um prato específico, vá até Pesquisar um Prato. Digite o nome e pressione Enter. O sistema consultará a enciclopédia enquanto você folheia as receitas.

Quando o resultado estiver pronto, o marcador de fita piscará suavemente e o canto da página ganhará um pulso. Vire a página para ver a receita.

Clique no marcador de fita vermelho a qualquer momento para voltar ao sumário.
